# spring-ai-hwl

Spring Boot 4.1 + Spring AI 2.0 的简单实践。

## 环境

- Java 21
- Spring Boot 4.1.1
- Spring AI 2.0.1

## 模块

| 模块                            | 说明                                              |
|-------------------------------|-------------------------------------------------|
| `spring-ai-01-base`           | ChatModel / ChatClient 基础聊天、流式输出、会话记忆           |
| `spring-ai-02-agent-patterns` | ReAct / Plan & Execute / Reflection 三种 Agent 模式 |
